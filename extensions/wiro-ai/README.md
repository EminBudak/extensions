# Wiro AI

Generate images and videos, chat with LLMs and search 1,000+ AI models on [Wiro AI](https://wiro.ai) from Raycast.

## Commands

- **Generate Image**: pick a text-to-image model, write a prompt and set the model's options, such as resolution, ratio or quality. Copy the image, save it or open it in your browser.
- **Generate Video**: make a video from a prompt or from an image on your Mac. Follow the task status while the model works, then open, copy or save the video.
- **Ask AI**: chat with LLMs from OpenAI, Anthropic, Google, DeepSeek, xAI, Qwen and others through the Wiro AI LLM gateway. Choose the model in the dropdown and ask follow-up questions in the same conversation. Type a question after the command name to start right away.
- **Search Models**: search the Wiro AI catalog by name, owner or task and filter it by category. See each model's details and starting price, then open its page or start Generate Image, Generate Video or Ask AI with it.

Model lists, settings and prices come from the live Wiro AI catalog. The forms show each model's main settings and every setting that changes the price, with the price for your settings at the bottom.

## Setup

1. Sign up at [wiro.ai](https://wiro.ai) and create a project at [wiro.ai/panel/project/new](https://wiro.ai/panel/project/new).
2. Open any Wiro AI command and paste the project's API key into **API Key**.
3. If you created the project with signature-based authentication, paste its API secret into **API Secret** as well. Leave it empty for an API Key Only project.

**Save Folder** sets where Save Image and Save Video put files. Your Downloads folder is used when it is empty.

## Pricing

Searching models is free. Model runs and chat messages are charged to your Wiro AI project's wallet at each model's price, and tasks that fail or that you cancel are not charged.
